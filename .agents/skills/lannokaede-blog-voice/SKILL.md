# lannokaede 个人博客写作风格指南

文章定位是**平实自然的技术分享**：用正常人写技术笔记的流畅句子，说清楚做了什么、用了什么技术、为什么这么设计、遇到什么问题以及怎么解决的。

## 1. 把握中间尺度

- **不加戏、不装口语**：不用“折腾”“顺手”“顺带”“搓了个”“干脆”“凑合”“破案了”“老老实实”这类刻意装熟的词，也不编心理描写和生活场景。
- **不机械化、不写流水账**：避免大量使用“现象：… / 排查：… / 验证：…”这类冰冷的表单体或电报式短句，用自然连贯的段落讲清因果。
- **只写有分享价值的技术内容**：删掉琐碎的个人流水账（如某天磁盘剩几 GB、卸载腾空间、某个游戏的启动器路径等），文章之间保持独立，少做跨篇联动。
- **模糊处理第三方平台**：涉及第三方中转 API、代理商或私人线路时，不写具体平台名，用「第三方中转线路」「第三方 API」等泛称带过。

## 2. 标题与事实边界

- **标题简短直接**：体现做了什么任务即可，不要把细节堆进标题。
- **保留真实边界**：不编造未提供的版本号、数据或测试结论；跑通的写跑通，未测的明确说明。
