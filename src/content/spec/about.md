# 关于

我是 **lannokaede**，电子科技大学软件工程在读。这个站平时主要用来放项目复盘和排查笔记，免得过几个月再碰上同一个坑，还得重新翻半天日志。

写得比较多的是 **Go 后端**、**本地 Agent 工具链**，偶尔也会顺手记一些装环境、搭自用服务或者排查网络问题的过程。文章尽量按实际踩过的过程写，跑通了写跑通，没测完也会直接标出来。

可以在 [GitHub](https://github.com/lannokaede)、[哔哩哔哩](https://space.bilibili.com/499115598) 找到我，有事也可以发邮件到 [lannokaede@gmail.com](mailto:lannokaede@gmail.com)。如果想跟进更新，直接订阅 [RSS](/rss.xml) 就行。
